a make.fun entry for
[The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

## The line

> Can't come in — I dreamt I was at work all night, so I've already done a full shift and I'm exhausted from it.

110 characters, one line, nothing else.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`)
and prints it.
